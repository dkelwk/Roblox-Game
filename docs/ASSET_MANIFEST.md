# Asset Manifest

The single record of every planned and produced asset. Update the row in the same change
that adds or modifies an asset. Every asset follows [ART_DIRECTION.md](ART_DIRECTION.md)
(stylized low-poly). Budget tiers are triangle ceilings: hero 4000, creature 2000, prop 800,
scatter 250.

**Status values**

| Status | Meaning |
|---|---|
| Planned | Not started |
| Blockout | Procedural stand-in exists in the world generator |
| Pilot | Blender asset built and previewed; awaiting creative-director approval |
| Approved | Signed off for import |
| Imported | In Studio and verified in-engine with a screenshot |
| Final | Replaced the blockout everywhere |

**Paths**

- Source: `blender/source/<Asset>.blend`, generated by `blender/scripts/build_<Asset>.py`
- Export: `blender/export/<Asset>.fbx`
- Preview: `docs/previews/<Asset>.jpg`
- Studio: `ReplicatedStorage.Assets.<Category>.<Asset>`, unless noted
